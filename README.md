## Описание проекта

Разработка системы автоматической классификации дерматоскопических изображений кожи для выявления меланомы. Модель использует сверточную нейронную сеть ResNet18 с переносом обучения (Transfer Learning).

### Цель работы
Создание вспомогательного инструмента для первичного скрининга меланомы, способного снизить нагрузку на врачей и ускорить диагностику.


## Датасет

**HAM10000** (Human Against Machine with 10000 training images)
- **Общее количество изображений:** ~10,000
- **Классы:** 7 типов образований (для бинарной классификации объединены в "Melanoma" vs "Benign")
- **Разрешение:** 450×600 пикселей
- **Источник:** [Kaggle](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000)

**Дисбаланс данных:** 
- Здоровые (Benign): ~89%
- Меланома (Melanoma): ~11%


## Результаты

### Основные метрики

| Метрика | Значение | Интерпретация |
|---------|----------|---------------|
| **AUC-ROC** | **0.863** | Хорошая дискриминация классов |
| **Accuracy** | 0.78 | Общая точность |
| **Recall (Sensitivity)** | **0.80** | Найдено 80% меланом |
| **Specificity** | 0.78 | 78% здоровых правильно определены |
| **Precision** | 0.30 | Много ложных срабатываний |
| **F1-Score** | 0.43 | Гармоническое среднее |

### Распределение вероятностей

![Probability Histogram](/images/probability.png)

**Интерпретация:**

- **Зеленая кривая (Benign):** Смещена влево (к 0) → модель уверена в здоровых пациентах
- **Красная кривая (Melanoma):** Смещена вправо (к 1) → модель распознает меланомы
- **Зона пересечения (~0.5):** Сложные случаи, требующие внимания врача

**Вывод:** Модель хорошо разделяет классы, но есть область неопределенности, где вероятности близки к порогу 0.5. В таких случаях следует говорить пациенту обратиться к врачу, для точной диагностики

### Вывод

**Модель готова к использованию в качестве вспомогательного инструмента скрининга.**

Несмотря на низкую точность позитивных предсказаний (Precision = 0.30), высокий показатель полноты (Recall = 0.80) делает систему полезной для первичного отбора пациентов. В медицинской диагностике приоритет отдаётся минимизации пропущенных заболеваний, поэтому ложные срабатывания считаются допустимым компромиссом.
